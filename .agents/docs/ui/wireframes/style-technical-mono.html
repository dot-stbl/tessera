Style study · technical mono

Tessera: сейчас → «technical mono»

Слева — текущие токены (снято с apps/console/src/index.css). Справа — тот же компонент на предлагаемых токенах. Разметка идентична: стиль почти целиком живёт в переменных, структурных правок ровно 7 (помечены в CSS как STRUCTURAL).

01

Что именно меняется

7 решений — всё остальное следствие
СлойСейчасTechnical monoЗачем
--f-label Onest / Geist (sans) JetBrains Mono, UPPERCASE, ls .09em Главный переключатель. Весь мета-слой (заголовки колонок, бейджи, лейблы, навигация) уходит в моно — контент остаётся в sans.
--radius 0.45rem → 7px 0; пилюли 1px Плоскость + линия вместо «мягкой карточки». Данные выглядят как таблица, а не как виджеты.
--border oklch(92%) — почти невидимая oklch(88.5%) + --border-2 как «сильная» линия Линия начинает нести структуру; исчезает потребность в тенях и разных фонах панелей.
тени карточки с 0 1px 2px нет вообще Глубина только через 1px-линию. Панели склеиваются в решётку на общих границах.
статусы пастельная заливка *-soft ghost-тег: ink + 1px рамка Снимает «леденцовый» шум с плотных таблиц; цвет остаётся, площадь цвета падает в ~5 раз.
акцент красный + 6 сервисных + 6 status-цветов конкурируют один акцент (deep red), сервисные −20% chroma Красный снова означает «действие / ошибка», а не «просто бренд».
плотность row 32px row 28px, tabular-nums везде +4 строки на экран; моно-цифры выравниваются в колонку без ручной ширины.

09

Что берём и что не берём

полный брутализм на APM ломает читаемость

берём

  • моно-мета-слой (лейблы, колонки, бейджи, крошки, nav);
  • --radius: 0, никаких теней, hairline как основной структурный приём;
  • ghost-теги для статусов и уровней; цвет остаётся, площадь падает;
  • один акцент; сервисная палитра тише акцента;
  • чипы фильтров как key=value — язык URL/YAML виден в UI;
  • blueprint-сетка только в пустых зонах (навигация, empty state, waterfall gridlines).

не берём

  • моно для длинного текста (сообщения ошибок, описания) — падает скорость чтения;
  • чёрные 2px рамки и offset-тени неубрутализма — на 30 строках это визуальный шум;
  • underlined-blue ссылки и системный Times — «сырой» брутализм, не наш регистр;
  • полный отказ от заливок: левый гуттер логов и выделение строки остаются заливкой;
  • UPPERCASE в данных (имена сервисов, операции) — ломает узнаваемость значений;
  • сетку под таблицами и waterfall — конкурирует с gridlines оси времени.

Патч токенов

apps/console/src/index.css — точки изменения 
/* ── :root ─────────────────────────────────────────────── */
- --radius: 0.45rem;
+ --radius: 0;                     /* pills → 1px, bars → 0 */
+ --radius-pill: 1px;

/* off-white / near-black вместо чистых #fff/#000 */
- --background: oklch(1 0 0);
+ --background: oklch(98.6% 0.002 250);
- --foreground: oklch(0.141 0.005 285.823);
+ --foreground: oklch(17% 0.008 250);

/* линия несёт структуру → контраст выше */
- --border: oklch(0.92 0.004 286.32);
+ --border: oklch(88.5% 0.004 250);
+ --border-2: oklch(78% 0.006 250);

/* status: soft-заливки становятся рамками */
+ --ok-bd:   oklch(72% 0.10 150);
+ --err-bd:  oklch(70% 0.14 25);
+ --slow-bd: oklch(75% 0.11 60);

/* сервисная палитра: chroma −20%, тише единственного акцента */
- --svc-1: oklch(0.60 0.12 250);  --svc-2: oklch(0.60 0.10 190);
+ --svc-1: oklch(0.54 0.09 250);  --svc-2: oklch(0.54 0.08 190);

/* ── @theme inline — новый мета-слой ────────────────────── */
+ --font-label: var(--font-mono);   /* главный переключатель стиля */
+ --tracking-label: 0.09em;

/* ── компоненты: 7 структурных правок ───────────────────── */
  1. .app-sidebar-section.is-active  фон → border-left 2px accent
  2. фильтр-чип                      capsule → key=value моно-тег
  3. thead th                        bg: surface-2 → transparent + border-2
  4. .span-row-error / tr.err-row    тонировка → inset 2px 0 0 var(--err)
  5. .pill-*, .log-level-*           soft-заливка → ink + 1px рамка
  6. .span-dot / service dot         border-radius: 50% → 0
  7. .span-bar                       radius 3px → 0, inset hairline 22%
  +  .dashboard-panel                 gap-решётка → общие границы (gap: 0)
  • файлы: apps/console/src/index.css (токены + 7 правил), components/ui/badge·pill (ghost-вариант), app-shell (sidebar rule), waterfall (bar/dot)
  • Ladle-каталог покажет регресс по всем ~110 примитивам сразу — прогонять после патча токенов, до правок компонентов
  • риски: контраст ghost-тегов на --card в тёмной теме (проверить AA для --ok-ink), и radius: 0 у Base UI popover/select — там скругление приходит из shadcn-слоя
